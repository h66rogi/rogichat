# 로기챗 브랜딩 기준

확정 제품명은 **로기챗**. 기술 식별자는 `rogichat`, 도메인은 `rogi.chat`을 사용한다.

- 웹 제목·메타데이터·OG·favicon·manifest·이메일·알림·오류 화면·앱 표시 이름·스토어
  문구는 로기챗 전용으로 만든다. 기존 로고·폰트 자산·배경·컬러 테마·사운드는 이식하지 않는다.
- 기존 지원/문의/정책/결제/다운로드 링크와 분석·고객지원 SDK 식별자를 제거한다.
  새 연락처·운영 주체·약관은 확정된 정보로만 작성한다.
- Android applicationId와 iOS bundle ID는 새 식별자를 발급하고 Firebase/APNs,
  associated domains, URL schemes, signing도 로기챗 전용으로 구성한다.
- 기존 소스에서 동작을 가져오더라도 UI/스토리북/fixture/screenshot/sample data에
  이전 서비스명이나 사용자 데이터가 남지 않게 출시 전 검색·화면 검토를 한다.
- 법적 라이선스/저작권 attribution은 필요한 위치에 보존한다. 제품 브랜딩 제거가
  소스 라이선스 삭제 권한을 뜻하지 않는다. 조사 문서의 원본 이름도 출처로 유지한다.

`api.meloming.com`은 사용자가 지정한 **인증 인프라 의존성**이다. 서버 측 allowlist와
인증 설계 문서에만 필요한 주소를 두고, 로그인 버튼과 완료/실패 화면은 로기챗으로 표시한다.
브라우저 주소창의 중계 hostname과 SOOP 동의 화면의 등록 앱 이름까지 숨길 수 있다고
약속하지 않는다. 기존 SOOP 앱이 기존 이름을 표시한다면 등록 설정 변경/별도 앱 등록과
다른 소비자 영향에 대한 별도 결정이 필요하다.
