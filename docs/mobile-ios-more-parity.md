# 멜로밍 iOS 1.2.3 더보기 화면과 로기챗 비교

2026-09-25 사용자 제공 iOS 화면은 멜로밍 **1.2.3 (26)**의 `더보기`다. 기준 소스는
`meloming-ios`의 build 26 시점 `d133fb4`에 연결된 `MainTabView → MoreView`와
`ServiceGridSection`이다. 검은 시스템 배경, 작은 상단 제목과 알림 아이콘,
60pt 로그인/프로필 행, 4열 서비스 격자, 둥근 목록의 `앱 정보` 섹션이 보인다.
현재 소스 `18a33bbf`에는 버전 문자열이 여전히 1.2.3 (26)이지만 2026-07-18
`d64a14d` 이후 탭 연결과 이름이 `MyPageView`/`마이`로 바뀌었다. 버전 문자열만으로
사용자 화면의 구현을 고르면 안 된다.

구현은 `d133fb4`의 `MoreView.swift`, `ServiceGridSection.swift`, `ServiceItem.swift`, `NotificationButton.swift`에서
본문·로그인 행·그리드 컴포넌트·모델을 직접 복사하고 로기챗 세션과 목적지 부분만 수정했다.
원본 `NavigationStack`은 이미 `AppShell`에 있어 중복하지 않았다.

| 영역 | 사용자 화면 / 멜로밍 1.2.3 | 로기챗 변경 전 | 이번 적용 |
| --- | --- | --- | --- |
| 상단 | `더보기` 작은 고정 제목, 오른쪽 알림 아이콘 | `설정` 큰 탐색 제목 | `더보기` 고정 제목, 실제 알림 설정으로 가는 아이콘 |
| 본문 | 시스템 검은 배경의 기본 `List`, 둥근 섹션 | 프로필 중심 `ScrollView`와 카드 | 원본 `List { listSections }` 및 섹션 코드 이식 |
| 프로필 | 비로그인 카드에 60pt 원형 아이콘·로그인 안내·화살표 | 76pt 프로필 행 | 60pt 행과 실제 로그인/프로필 이동 |
| 서비스 | 4열 48pt 색상·이모지 타일 | 없음 | 원본 `ServiceGridSection`/`ServiceItem` 복사 후 실제 열 수 있는 홈·대화·알림 설정·화면 모드만 제공 |
| 앱 정보 | 고객센터·약관·개인정보·버전·라이선스가 한 섹션에 직접 표시 | 별도 `로기챗 정보` 화면 | 별도 화면 제거. 실제 공개된 이용 안내·번들 버전·라이선스를 한 섹션에 직접 표시 |
| 계정 | 로그인 시 설정·로그아웃 별도 섹션 | 계정 관리 화면에 로그아웃 | 실제 계정 기능과 로그아웃을 더보기 목록에서 제공 |

로기챗에는 아직 멜로밍의 서비스 8개, 알림함·미확인 배지, 확정된 고객센터·약관·
개인정보처리방침 공개 목적지가 없다. 버튼을 만들어 연결된 것처럼 보이지 않게 한다.
`/rules`는 채팅 이용 안내이며 약관이나 개인정보처리방침으로 표기하지 않는다.
QA에만 존재하고 운영에서는 404인 일정·노래책·옷장·셋리스트는 앱 격자에 넣지 않는다.
채팅 UX는 사용자 요청에 따라 이 비교에서 제외한다.

검증 범위: 소스와 사용자 화면의 구조 대조, iOS QA/Prod 빌드, 기존 탐색·로그아웃
동작 확인. 실제 기기에서 다크/라이트·큰 글자·VoiceOver의 시각 비교는 별도 검증한다.
