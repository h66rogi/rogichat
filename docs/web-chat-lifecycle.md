# 웹 채팅 수명 주기 결정

2026-09-24. 범위: 웹 인증 쿠키, 서버 렌더링, 채팅 재진입, 실시간 동기화.

## 쿠키와 첫 화면

최신 QA 세션은 `Domain=qa.rogi.chat`의 `__Secure-rogi_qa_session` HttpOnly 쿠키다. 운영 세션은 별도 이름인 `__Secure-rogi_prod_session`이다. 웹 서버는 현재 환경의 쿠키 이름만 읽어 API에 전달한다. QA 웹에 함께 도착할 수 있는 운영 쿠키는 전달하지 않는다. 브라우저에 bearer를 노출하거나 별도 인증 세션을 만들지 않는다. 모든 서버 조회에서 API가 현재 세션과 권한을 다시 검사한다.

로그아웃·탈퇴를 시작하면 웹 호스트 전용 HttpOnly 렌더링 잠금 쿠키를 먼저 설정한다. 이 동안에는 API 세션 쿠키를 유지해 결과가 불확실한 작업을 재확인할 수 있지만, Next 서버는 비공개 본문을 렌더링하지 않는다. 로그아웃 확인 또는 탈퇴 복구 의도 해제 뒤에만 잠금을 해제한다.

Next 서버는 웹 쿠키로 현재 API 세션·프로필을 읽어 인증 화면을 SSR한다. 채널의 기본 방·membership·프로필·수신자·최근 메시지도 현재 API 응답에서만 읽어 첫 `/chat` 화면에 전달한다. 응답은 요청 범위에서만 사용하며 `no-store`다. 다중 페이지 또는 일시적 API 오류에는 스켈레톤과 기존 클라이언트 재시도 경로가 남는다. 서버가 렌더링한 권한도 이후 명령의 권한 증명이 아니며 각 API 요청이 재검사한다.

## 라우트 복귀와 동기화

채팅방 컴포넌트·작성 중인 초안·스크롤은 채널 메뉴 이동 동안 유지한다. 다른 메뉴에서는 소켓·푸시 바인딩·15초 주기 조회를 중지한다. 돌아올 때 이미 보이는 대화 DOM을 유지하고 이전 읽기·전송 종료 뒤 새 권한과 변경 이벤트만 확인한다. 탭 숨김·pagehide에서는 비공개 화면을 스켈레톤으로 가리고 컴포넌트와 네트워크 연결을 분리한다. bfcache 또는 탭 복귀 시 API 세션을 다시 확인한 뒤 같은 세션이면 최신 스냅샷과 미확인 전송 결과를 검증하면서 기존 입력 DOM을 유지한다. 권한 거부·세션 변경 시에는 화면과 메모리를 즉시 비운다.

메뉴를 떠나며 보관한 초안은 같은 인증 세션 동안 유지한다. 시간 경과만으로 지우지 않는다. 접근 권한이나 세션이 바뀌면 관련 메모리를 비운다. 전송 저장소 오류는 화면에서 복구 절차를 안내하지 않고 백그라운드에서 다시 확인한다. 메시지를 보낼 수 없는 동안에는 간결한 안내만 표시한다.

겹친 포커스·복귀 이벤트는 진행 중인 세션 확인을 공유한다. 명시적인 로그아웃·계정 변경·권한 무효화는 그 확인을 취소하고 새로 검사한다. 실시간 소켓과 웹 푸시는 변경 힌트이고, 내용과 접근 권한의 원본은 API와 DB다. 동기화 중 추가 힌트가 오면 현재 조회 뒤 한 번 더 읽는다.

## 검증 기준

- 첫 채팅 렌더링은 현재 API 권한과 메시지에서 시작하고, 미확인 구간에는 스켈레톤을 사용한다.
- 메뉴 이동 후 복귀 시 동일한 입력 DOM·초안·스크롤이 유지되고 백그라운드 권한 조회가 수행된다.
- 권한 취소·로그아웃·탈퇴 pending 상태에는 이전 대화와 초안이 제거된다.
- SSR은 현재 환경의 쿠키만 API에 전달하고 다른 환경 쿠키와 pending 상태에서는 비공개 내용을 표시하지 않는다.
- QA 배포 후 이미지 digest, `/chat`, `/healthz`, API `/ready`와 실제 브라우저 경로를 확인한다.
